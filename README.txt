えっちゃん AI司令室 v1.0
==========================
【今回実装した内容】
1. 16人のAI社員から担当選択
2. 依頼文の自動組み立て、コピー、ChatGPTへの入口
3. よく使う8種類の依頼ひな型
4. 既存アプリ用ランチャー（URLは設定画面から登録）
5. ローカルToDoの追加・完了・削除
6. 既存通知4件の参照メモ（状態の自動同期はしない）
7. ToDoとURL設定のJSONバックアップ／復元
8. スマホ／PC対応のレスポンシブ画面とPWA基本ファイル
9. URLを設定するまで、既存アプリには影響を与えません。

【PCで試す】
index.html をブラウザで開くと基本画面を利用できます。
ローカルファイル起動の場合、ブラウザによって保存が制限されることがあります。

【iPhoneのホーム画面に追加する】
GitHub Pages等、HTTPSでindex.html・manifest.webmanifest・sw.js・icons/を同じ場所に配置し、SafariでそのURLを開く。
共有メニュー → ホーム画面に追加。
※ GitHub Pagesへの公開作業はまだ実施していません。
※ 元のGitHubプロジェクトは変更していません。

【利用上の制限】
・ChatGPTへの送信／Codexの実行／GitHub同期／Google Drive同期は未実装です。
・AI社員は指示文の担当として動作します。独立したAIエージェントではありません。
・ToDoはChatGPTの自動通知と連動しません。
・各アプリのURLは未設定です。確認できないアドレスを作り込まないようにしています。
・自動ログインやトークンの保存はしません。
・仕事の機密情報は入力せず、承認された社内Copilot環境を利用してください。
・初回表示の未完了ToDoは、過去の会話で確認できている『標準からリスク展開アプリ』のみです。これ以降は手動更新です。

【次段階の設計】
・個人用のみでの外部連携権限確認
・GitHub Pages公開
・各アプリの正規URL登録
・ChatGPTの自動通知とアプリToDoを連携するには別の認証付きサーバが必要
・会社用Copilotは社内承認のある仕組みで別構築
